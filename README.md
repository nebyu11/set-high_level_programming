# Set High Level Programming

This repository contains Python and C programming tasks for the **SE 202: High Level Programming I** course.

## Directories

- [python-hello_world](./python-hello_world) - Introduction to Python syntax, basic output printing, compiling, and running scripts.
- [python-if_else_loops_functions](./python-if_else_loops_functions) - Branching, loops, functions, and linked list insertions in C.
- [python-import_modules](./python-import_modules) - Importing functions, variables, modules, command-line arguments parsing, and CPython internals.
- [python-data_structures](./python-data_structures) - Lists, tuples, matrix processing, linked list palindrome checking in C, and CPython list information.
- [python-more_data_structures](./python-more_data_structures) - Dictionaries, sets, list mapping, weighted averages, and CPython list and byte object introspection.
- [python-classes](./python-classes) - Classes, objects, instantiation, encapsulation, type/value validation of fields, getters/setters, instance methods.
- [python-more_classes](./python-more_classes) - More classes, properties, custom representation, instance counts, static/class methods, and backtracking solvers.
- [python-everything_is_object](./python-everything_is_object) - Mutability vs immutability, variables, references, identity, equality, interning, and passing arguments.
- [python-inheritance](./python-inheritance) - Inheritance, superclass, subclass, class lookup, overriding methods, isinstance/issubclass built-in functions.
- [python-input_output](./python-input_output) - File handling, reading/writing UTF-8 text files, JSON serialization, Student classes, Pascal's triangle, and stream stats.
- [python-test_driven_development](./python-test_driven_development) - Test-driven development (TDD), doctests, unittests, matrix operations, and CPython string inspection.
- [python-almost_a_circle](./python-almost_a_circle) - Object-oriented programming, inheritance, class hierarchy (`Base`, `Rectangle`, `Square`), JSON/CSV serialization, and Turtle GUI drawing.
- [python-object_relational_mapping](./python-object_relational_mapping) - MySQL database interaction using `MySQLdb` and object-relational mapping using `SQLAlchemy`.
- [python-network_0](./python-network_0) - HTTP networking, cURL requests, headers, methods, status codes, and an $O(\log n)$ peak-finding algorithm.
- [python-network_1](./python-network_1) - Network requests using Python `urllib` and `requests` packages, JSON REST API parsing, and GitHub API integration.
