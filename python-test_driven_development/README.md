# Python - Test-driven development

This directory contains tasks introducing test-driven development (TDD) in Python. It includes functions for integer addition, matrix division, string formatting, shape printing, and text indentation, as well as their corresponding doctests and unittests.

## Tasks
- **0-add_integer.py**: Adds two integers/floats and tests.
- **2-matrix_divided.py**: Divides all elements of a matrix and tests.
- **3-say_my_name.py**: Prints formatted first and last name and tests.
- **4-print_square.py**: Prints a square with `#` character and tests.
- **5-text_indentation.py**: Prints text with 2 new lines after `.`, `?`, and `:` and tests.
- **6-max_integer.py**: Function finding max integer in a list.
- **tests/6-max_integer_test.py**: Unittests for `max_integer`.
- **100-matrix_mul.py**: Multiplies two matrices and tests.
- **101-lazy_matrix_mul.py**: Multiplies two matrices using NumPy and tests.
- **102-python.c**: C function inspecting CPython string objects.
